# Wiki: Git Lab 11-12

## Призначення проекту

Цей навчальний проект демонструє базові можливості Git та GitHub: створення репозиторію, роботу з комітами, гілками, Pull Request та Issues.

## Структура

- `README.md` — опис проекту та коротка інструкція.
- `main.py` — демонстраційна програма для аналізу тексту.
- `docs/wiki.md` — коротка документація у форматі Wiki.

## Основні команди

```bash
git status
git add README.md main.py
git commit -m "Початковий коміт: readme і код"
git branch feature-01
git checkout feature-01
git merge feature-01
```

## Висновок

Репозиторій можна використовувати як приклад виконання лабораторної роботи з теми Git та GitHub.
