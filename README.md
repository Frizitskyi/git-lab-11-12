# Git Lab 11-12

Демонстраційний проект для лабораторної роботи з Git та GitHub.

## Опис

Репозиторій створено для практичного освоєння Git: конфігурації, локального та віддаленого репозиторію, комітів, гілок, Pull Request, Issues та Wiki.

## Встановлення

Склонуйте репозиторій:

```bash
git clone https://github.com/Frizitskyi/git-lab-11-12.git
```

## Використання

Запустіть файл `main.py`:

```bash
python main.py
```
